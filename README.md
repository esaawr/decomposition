# BSA 00 — Анализ и проектирование ИТ-систем

Учебный проект по дисциплине «Бизнес-системный анализ» (BSA).  
В рамках проекта выполнены задания по двум предметным областям: **сеть барбершопов (BRB)** и **служба доставки заказов (DEL)**.

---

## 📁 Структура проекта
src/
├── BRB/ # Проект «Барбершоп»
│ ├── ex01_BRB_infosources.xlsx # Каталог источников информации
│ ├── ex02_BRB_glossary.xlsx # Глоссарий терминов
├── DEL/ # Проект «Служба доставки»
│ ├── ex01_DEL_infosources.xlsx # Каталог источников информации
│ ├── ex02_DEL_glossary.xlsx # Глоссарий терминов
├── ex03_decomposition.docx # Демографическая пирамида РФ (декомпозиция)
├── ex04_types.docx # Виды декомпозиции (завтрак)
├── ex05_types.docx # Декомпозиция действий курьеров и ролей
├── ex06_rules.docx # Правила декомпозиции (активности дня)


> **Примечание:** Задания ex03–ex06 являются общими для обоих проектов и выполняются на примере абстрактных задач (демографическая пирамида, завтрак, доставка, распорядок дня). В рамках каждого проекта они размещены в соответствующей директории.

---

## 📌 Выполненные задания

### Exercise 00 — Создание пространства
- Определены префиксы продуктов: **BRB** (барбершоп), **DEL** (доставка).
- Созданы отдельные директории в `src/`.

### Exercise 01 — Выявление источников информации
- Для каждого проекта создан каталог источников информации (не менее 5 источников).
- Указаны приоритет изучения, актуальность, легитимность, дата занесения, отметка об изучении и примечания.

**Файлы:**
- `ex01_BRB_infosources.xlsx`
- `ex01_DEL_infosources.xlsx`

### Exercise 02 — Создание и ведение глоссария
- Для каждого проекта создан глоссарий (не менее 10 понятий).
- Указаны определения, источники и даты добавления.

**Файлы:**
- `ex02_BRB_glossary.xlsx`
- `ex02_DEL_glossary.xlsx`

### Exercise 03 — Основные понятия декомпозиции
- Найдена демографическая пирамида РФ.
- Определены: показатель разбиения (возраст, пол), цель составления, вид декомпозиции (структурная), количество уровней (3), критерии разбиения.
- Описан порядок построения пирамиды.

**Файлы:**
- `ex03_decomposition.docx`

### Exercise 04 — Виды декомпозиции
- Рассмотрена декомпозиция завтрака (вареное яйцо, тост с маслом, сок, чай).
- Определены цель, вид, количество уровней.
- Найдены и исправлены ошибки: нарушение подчинённости, целостности, логическая ошибка.
- Построена объектная декомпозиция завтрака до уровня 2 с указанием критериев разбиения.

**Файлы:**
- `ex04_types.docx`

### Exercise 05 — Виды декомпозиции (задача «Доставка»)
- Изучена задача 2 (Chapter IV).
- Разработана функциональная декомпозиция действий курьеров (3 уровня).
- Разработана объектная декомпозиция действующих лиц (ролей) задачи (3 уровня).

**Файлы:**
- `ex05_types.docx`

### Exercise 06 — Правила декомпозиции
- Перечислены 14 активностей дня.
- Определены 2 цели декомпозиции с указанием пользователей и потребностей.
- Построена событийная декомпозиция активностей дня для каждой цели.

**Файлы:**
- `ex06_rules.docx`

## 🛠️ Инструменты

- **Форматы документов:** `.docx` (текстовые отчёты), `.xlsx` (каталоги, глоссарии).
- **Схемы декомпозиции:** построены в графическом редакторе (draw.io / Miro / аналоги).
- **Система контроля версий:** Git.

## 📚 Теоретическая база

Основные понятия и правила декомпозиции, жизненный цикл разработки ИТ-систем, методы выявления источников информации и ведения глоссария — см. файл:

- `1. Жизненный цикл разработки ИТ-систем.txt`

## 🎯 Цели проекта

1. Освоить методы сбора и систематизации информации об ИТ-задаче.
2. Научиться строить декомпозиции различных видов (функциональная, объектная, структурная, событийная).
3. Применять правила декомпозиции: подчинённость, единственность критерия, целостность.
4. Отработать навыки оформления аналитических артефактов.
